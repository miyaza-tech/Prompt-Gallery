========================================
📁 상세 설명
========================================

css/ - 커스텀 스타일
  - 모달 애니메이션 (fadeIn, slideUp)
  - 스크롤바 커스터마이징
  - Tailwind로 불가능한 추가 스타일

js/app.js - 메인 애플리케이션 로직
  [전역 상태]
  - items[], currentUser, selectedCategories[], activeFilters[]
  
  [Cloud Firestore]
  - loadItems(): getDocs 조회 (created_at 내림차순)
  - docToItem(): 문서 → 아이템 변환 (id + ISO created_at)
  - saveItemWithImage(): addDoc / updateDoc
  - deleteItem(): deleteDoc + Storage 이미지 삭제
  - importItemsToFirestore(): JSON 일괄 등록 (writeBatch, 400개 단위)

  [Firebase Storage]
  - uploadImageToStorage(): 파일 업로드 (10MB)
  - deleteImageFromStorage(): 이미지 삭제 (직접 업로드한 파일만)

  [Realtime 동기화]
  - subscribeToRealtime(): onSnapshot 리스너 등록
  - unsubscribeFromRealtime(): 로그아웃 전 반드시 호출

  [Authentication]
  - checkAuthStatus(): 로그인 상태 확인
  - login(), logout(): 인증 처리
  - updateUIForAuth(): 권한별 UI 제어
  
  [UI 관리]
  - toggleForm(), closeEditForm(): 모달 제어
  - toggleCategory(), toggleEditCategory(): 다중 선택
  - filterItems(): 다중 필터링 (OR 조건)
  - renderGallery(), createItemCard(): 렌더링

js/firebase-config.js - Firebase 설정 (ES module)
  - firebaseConfig (apiKey, projectId, storageBucket ...)
  - COLLECTION = 'prompts', IMAGE_FOLDER = 'prompt-images'
  - Firebase SDK v12.16.0 을 gstatic CDN 에서 import
  - window.fb 로 auth/db/storage 와 필요한 함수들 노출

========================================
🗄️ Firebase 구조
========================================

Cloud Firestore:
  - Collection: "prompts"
    * (문서 ID) - Firestore 자동 생성 문자열
    * prompt (string)
    * category (string) - 쉼표로 구분된 다중 카테고리
    * sref (string)
    * image (string) - Storage 다운로드 URL 또는 외부 URL
    * created_at (timestamp) - 정렬 기준, 없으면 목록에서 누락됨

Storage:
  - Folder: "prompt-images/"
    * 이미지 파일 저장 (최대 10MB, image/* 만 허용)
    * 무료 사용량: 5GB (약 5,000개 이미지)
    * ⚠️ Blaze(종량제) 요금제 필수 - 2026-02-03부터 결제 계정 연결 필요

Authentication:
  - Email/Password 로그인
  - 관리자 계정만 콘솔에서 수동 생성

Realtime:
  - onSnapshot() 리스너
  - 문서 추가/수정/삭제 실시간 감지

========================================
🔒 보안 규칙
========================================

Firestore (prompts) - firestore.rules:
  🔒 read/write: request.auth != null

Storage (prompt-images/) - storage.rules:
  ✅ read: 누구나 가능 (img 태그용)
  🔒 write: request.auth != null + 10MB 미만 + image/* 만
  🔒 delete: request.auth != null
